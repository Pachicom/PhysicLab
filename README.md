# PhysicsLab — интерактивная лаборатория

Учебный проект на HTML, CSS, JavaScript и Canvas API. Работает локально, не требует сборки, npm или серверной части.

## Возможности
- Интерактивная модель математического маятника: длина, начальный угол, ускорение свободного падения, период и частота.
- Геометрическая модель прямоугольного треугольника по теореме Пифагора.
- Эксперимент с пружиной по закону Гука: сила, жёсткость и удлинение.
- Электрическая цепь по закону Ома: напряжение, сопротивление, сила тока и мощность.
- Canvas-визуализации и анимации, управляемые JavaScript.
- Тест из 10 вопросов с обратной связью и сохранением последних результатов в localStorage.
- Раздел о методике исследования эффективности обучения.
- Адаптивная тёмная тема.
- В HTML, CSS и JavaScript добавлены поясняющие комментарии к строкам исходного кода.

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в современном браузере.
3. Интернет не нужен для работы моделей; веб-шрифт используется только как необязательное улучшение.

## Файлы
- `index.html` — структура сайта и интерфейс четырёх экспериментов.
- `style.css` — оформление, адаптивная вёрстка и эффекты.
- `script.js` — математические расчёты, Canvas-отрисовка, анимации и тест.

## Формулы моделей
- Маятник при малых колебаниях: `T = 2π√(L/g)`, `θ(t) = θ₀ cos(√(g/L) · t)`.
- Прямоугольный треугольник: `c = √(a²+b²)`.
- Закон Гука: `F = kx`, поэтому `x = F/k` в пределах упругой деформации.
- Закон Ома: `I = U/R`; электрическая мощность в модели рассчитывается как `P = U·I`.

## Быстрые проверки
- Маятник: при `L = 1 м` и `g = 9,81 м/с²` период примерно `2,01 с`.
- Пифагор: при катетах `3` и `4` гипотенуза равна `5`.
- Пружина: при `F = 10 Н` и `k = 10 Н/м` удлинение равно `1 м`.
- Закон Ома: при `U = 12 В` и `R = 3 Ом` ток равен `4 А`, мощность равна `48 Вт`.

## Ограничения
Модель маятника не учитывает сопротивление воздуха и трение, а формула периода предполагает малые колебания. Пружина моделируется в линейной области упругой деформации. Электрическая цепь — учебная идеализированная схема постоянного тока, а движущиеся точки служат визуализацией, а не точным изображением электронов. Результаты исследования эффективности обучения необходимо получить в реальном эксперименте; в проекте нет выдуманных результатов.


## Дополнительные интерактивные эксперименты (версия 2)

К четырём исходным моделям добавлены ещё девять: **закон всемирного тяготения Ньютона**, **закон преломления света**, **сохранение механической энергии**, **закон Лапласа для мыльного пузыря**, **волновое уравнение**, **Евклидова геометрия**, **циклоида**, **подобие треугольников**, **минимальная поверхность-катеноид**. В сумме доступно 13 уникальных моделей. Теорема Пифагора уже была в первоначальной версии, поэтому второй раз она не дублируется.

- Тяготение: `F = G m₁m₂/r²`. Визуальная схема условная, сила вычисляется в единицах СИ.
- Преломление: `n₁ sin θ₁ = n₂ sin θ₂`; для полного внутреннего отражения выводится отдельный статус.
- Механическая энергия: `E = mgh + mv²/2`; трение не учитывается, поэтому полная энергия сохраняется.
- Закон Лапласа для мыльного пузыря: `ΔP = 4γ/r` (две поверхности плёнки; для одной поверхности коэффициент был бы 2).
- Волна: `λ = v/f`; график показывает синусоидальную форму, не является измерением реальной среды.
- Евклидова геометрия: сумма внутренних углов плоского треугольника — 180°.
- Циклоида: `x = R(t − sin t)`, `y = R(1 − cos t)`.
- Подобие: стороны относятся как `k`, площади — как `k²`.
- Минимальная поверхность: визуализирован катеноид. Уточнение: уравнение Лапласа `Δu = 0` — уравнение гармонических функций и приближение при малых наклонах; общее уравнение минимальной поверхности нелинейно.

Все новые параметры можно менять ползунками, а кнопка «Сбросить параметры» возвращает исходные значения. Схемы предназначены для обучения и не заменяют точные физические измерения.


## Обновление: анимация в реальном времени и раздельные тесты

- Девять дополнительных моделей теперь обновляются непрерывно через `requestAnimationFrame`: частицы гравитационного взаимодействия, импульсы светового луча, движение тела и обмен энергией, динамические маркеры на пузыре, бегущая волна, контрольная точка треугольника, циклоидальная траектория, сравнение масштабов и вращающаяся проекция катеноида.
- Расчётные значения моделей обновляются вместе с кадрами анимации. Изменение ползунков по-прежнему меняет исходные параметры и результаты.
- В «Проверке знаний» доступны отдельные тесты «Физика» и «Геометрия» по 10 вопросов каждый.
- В истории попыток показывается предмет, результат и дата. История сохраняется локально в браузере.
- Анимация реализована на встроенном Canvas API и не требует внешних библиотек или подключения к интернету.
